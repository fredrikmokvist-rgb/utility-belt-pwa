# Anti-gravity PDF Editor

A high-performance, progressive web application (PWA) for editing PDF documents directly in the browser. 

**Built with Privacy in Mind: All processing happens locally in the browser.** No documents are ever uploaded to an external server.

## Features

- **Client-side Processing:** Total privacy and fast performance by manipulating PDFs directly on your device.
- **PWA Support:** Installable on desktop and mobile platforms with offline capabilities and native feel.
- **Virtual Rendering:** High-performance "Anti-gravity" engine using local workers and offscreen canvases to ensure the main UI thread is never blocked.
- **Structural Editing:** Drag-and-drop page reordering, page rotation, deletion, and seamless merging of multiple PDF files.

## Setup Instructions

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open `http://localhost:3000` in your browser.
